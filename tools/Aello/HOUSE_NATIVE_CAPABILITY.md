# House of Electra · Native Capability

Aello knows the native capability space so she does not mistake an old browser technique for a limitation of future Orbo.

## Primary

```text
SwiftUI
Canvas / GraphicsContext
Shape / Path
Charts / Chart3D
```

## Available when needed

```text
Core Animation
Core Graphics
```

## Escalation only

```text
Metal
RealityKit
```

## Shared law

> **Use the smallest native Swift presentation tool capable of faithfully realizing the visual law. No framework is privileged. Heavier tools enter only when a real specimen proves they are necessary.**

## Aello boundary

Aello may use this map to recognize what is possible and to avoid preserving implementation baggage merely because the prototype needed it.

**Aello does not assign a native tool. Ocypete chooses and proves the implementation.**
