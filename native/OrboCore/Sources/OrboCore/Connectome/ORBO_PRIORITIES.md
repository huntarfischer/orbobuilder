# Orbo Priorities

These priorities govern Connectome and Loom work.

1. **Field Theory Astrology is the ground of Orbo.** Orbo exists to demonstrate it. A design decision that contradicts Field Theory is wrong.

2. **Natural law is a design specification.** Prefer the behavior of the physical and celestial system over conventional application abstractions.

3. **One source, one door.** The same truth should have one authoritative route. A second path that can produce the same answer is a defect.

4. **Maximum-fidelity celestial truth stays authoritative.** Coarser representations are deliberate projections used only where the stored or indexed truth does not change at finer resolution.

5. **Materialize expensive, stable truth. Derive cheap or extremely dense truth locally.** Persistence follows the nature of the fact, not a blanket rule.

## Product frame

Orbo is a celestial-time instrument.

The sky is the source of truth. Structural engines establish relationships without interpretation. Technique engines ask astrological questions. Interpretation comes afterward.

## Build test

For any architectural decision, ask:

```text
Does it obey Field Theory?
Does it follow natural law?
Does it create or duplicate an authority?
Does it preserve the highest-fidelity truth?
Should this truth be materialized or locally derived?
```
