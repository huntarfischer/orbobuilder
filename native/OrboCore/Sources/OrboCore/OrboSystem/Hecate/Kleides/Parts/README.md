# Part Kleis

This shelf holds Hecate's astrological Part spells.

The frozen ingestion catalogue contains 155 distinct Parts representing 156 source occurrences across natal, annual/conjunction, mundane/weather, agricultural, and horary contexts.

All Part declarations are registered in `Kleides.canonical` at L3 only. This shelf contains catalogue matter only: no Part arithmetic, formula-selection policy, recommendation logic, interpretation, or downstream Orbo integration is implemented here.
