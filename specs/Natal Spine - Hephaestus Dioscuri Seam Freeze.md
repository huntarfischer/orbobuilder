# Natal Spine — Hephaestus / Dioscuri Seam Freeze

**Status:** FROZEN  
**Date:** 2026-08-31  
**Scope:** Natal Spine forge verification seam

## Frozen handoff

The lawful Dioscuri assignment is:

```text
Atropos-certified Natal Spine schematics
                +
forged Natal Spine candidate
                +
read-only canonical parent Mundane OrboSpine
                ↓
             Dioscuri
                ↓
      approval or divergence
                ↓
           Hephaestus
                ↓
           seal / refuse
```

No second schematics package is created for Dioscuri.

The candidate already carries the original `NatalSpineForgeCommission`, which binds the Atropos-certified schematic set to the forge. Dioscuri also receive that certified schematic set as the independent authority for native-layer fidelity.

The canonical parent Mundane OrboSpine is separately supplied as the independent authority for inherited celestial matter.

## Seal law

Hephaestus cannot seal a Natal Spine candidate until Dioscuri approval exists.

A provenance string, forge record, or candidate-carried assertion cannot substitute for independent comparison against canonical authority.
